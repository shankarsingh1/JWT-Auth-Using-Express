# JWT Authentication with Express.js

A simple and clean implementation of **JWT-based authentication** using **Node.js** and **Express.js**.  
This project demonstrates how signup, signin, token verification, and protected routes work using JSON Web Tokens.

---

## 🚀 Features

- User Signup
- User Signin
- JWT Token Generation
- Authentication Middleware
- Protected Route (`/me`)
- Stateless Authentication (No sessions)

---

## 🛠 Tech Stack

- Node.js
- Express.js
- JSON Web Token (JWT)
